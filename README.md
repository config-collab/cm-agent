# CM Consulting Agent

A comprehensive Configuration Management (CM) consulting platform designed to help organizations build knowledge bases, understand CM best practices, and implement effective configuration management strategies.

## Overview

The CM Consulting Agent is an interactive suite of tools that provides expert guidance on Configuration Management initiatives. Built with modern web technologies, it delivers step-by-step guidance, contextual learning, and practical implementation strategies for development teams and enterprises.

This agent is part of the **CM Booster** initiative - the future of Configuration Management consulting at Accenture.

## Tools & Components

### 1. **CM Contextualizer** (`cm-contextualizer.html`)
Build your organization's knowledge base with intelligent contextualization.

**Features:**
- Step-by-step wizard for setting up LLM providers
- Privacy-first configuration
- Document ingestion and processing
- Knowledge base building from organizational documents
- Results export and management
- Support for multiple document formats and providers

**Use Cases:**
- Establish organizational CM knowledge base
- Configure AI providers for contextual learning
- Manage document ingestion workflows
- Generate insights from organizational CM practices

### 2. **CM Guide** (`cm-guide.html`)
Configuration Management guidance for developers and teams.

**Features:**
- Interactive chat-based consulting interface
- Real-time CM recommendations
- Best practices for developers
- Implementation workflows
- Multi-tab navigation for different CM aspects
- Context-aware guidance

**Use Cases:**
- Get CM best practices for your specific scenario
- Understand CM implementation strategies
- Developer-focused CM guidance
- Real-time consulting on CM challenges

### 3. **CM Guide Extended** (`cm-guide_1.html`)
Additional CM resources and advanced guidance topics.

**Use Cases:**
- Extended CM scenarios and use cases
- Advanced implementation patterns
- Enterprise-level CM strategies
- Additional reference materials

## Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, or Edge)
- No installation required
- No backend dependencies

### Getting Started

1. **For Knowledge Base Setup:**
   - Open `cm-contextualizer.html` in your browser
   - Follow the 4-step wizard to configure your LLM provider
   - Ingest your organization's CM documents
   - Export your generated knowledge base

2. **For CM Guidance:**
   - Open `cm-guide.html` in your browser
   - Start asking questions about CM best practices
   - Navigate through different guidance topics using the tab interface
   - Reference the real-time recommendations

3. **For Extended Resources:**
   - Open `cm-guide_1.html` in your browser
   - Access additional CM guidance and resources

- No build process required

## Configuration

### LLM Provider Setup
The CM Contextualizer guides you through:
1. **Provider Selection** - Choose from supported LLM providers
2. **API Configuration** - Set up authentication and endpoints
3. **Privacy Settings** - Configure data handling preferences
4. **Knowledge Base** - Ingest and process organizational documents

### Supported Features
- Multiple LLM providers
- Document upload and processing
- Knowledge base export
- Results management and tracking
